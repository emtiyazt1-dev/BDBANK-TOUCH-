# SmartBank X v3
Aggressive mobile banking/MFS demo UI + Android Studio WebView project.
Features: persistent demo wallet, working send/payment balance validation, transaction search/history, premium card designs, card controls, receive/request, bank/international demo transfer, bill/recharge flows, QR display, FX, savings goals, analytics, security toggles, notifications and support.
This is a frontend/demo and does not process real money or connect to real banking networks. Production requires secure backend, authentication/OTP, KYC/AML, encrypted APIs, database, fraud monitoring and licensed integrations.
